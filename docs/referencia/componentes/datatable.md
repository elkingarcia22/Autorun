# 📦 DataTable

> **Componente UBITS:** `datatable`  
> **API:** `window.createDataTable()` o `<ubits-datatable>`  
> **Storybook:** https://ubits-storybook10.vercel.app/?path=/story/datatable--default

## 🎯 Descripción

Tabla de datos UBITS con soporte para columnas fijadas, reordenamiento, ordenamiento, selección múltiple, filas expandibles y menú de columnas.
