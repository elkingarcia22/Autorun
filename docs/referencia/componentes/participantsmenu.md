# 📦 ParticipantsMenu

> **Componente UBITS:** `participantsmenu`  
> **API:** `window.createParticipantsMenu()` o `<ubits-participantsmenu>`  
> **Storybook:** https://ubits-storybook10.vercel.app/?path=/story/participantsmenu--default

## 🎯 Descripción

Componente de menú lateral UBITS para mostrar una lista de participantes. Incluye búsqueda, filtro y lista de participantes con avatar, nombre, rol y estado.
