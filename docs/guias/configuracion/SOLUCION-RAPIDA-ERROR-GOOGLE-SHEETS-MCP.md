# ⚡ Solución Rápida: Error Google Sheets MCP

**Error:** `Authentication Error: No authentication method provided`

---

## 🚀 Solución en 30 Segundos

Ejecuta este script:

```bash
node scripts/fix-google-sheets-mcp-error.js
```

El script te dará 3 opciones:
1. **Eliminar Google Sheets MCP** (si no lo necesitas)
2. **Configurar OAuth 2.0** (recomendado, similar a Figma/Vercel)
3. **Configurar Service Account** (tradicional)

---

## 📋 Opción 1: Eliminar (Más Rápido)

Si no necesitas Google Sheets MCP:

1. Ejecuta: `node scripts/fix-google-sheets-mcp-error.js`
2. Selecciona opción `1`
3. Reinicia Cursor

---

## 📋 Opción 2: OAuth 2.0 (Recomendado)

1. Ejecuta: `node scripts/fix-google-sheets-mcp-error.js`
2. Selecciona opción `2`
3. Ingresa tu Client ID de Google Cloud
4. Reinicia Cursor
5. Autoriza en el navegador (se abrirá automáticamente)

**Ventajas:**
- ✅ Similar a Figma/Vercel
- ✅ No requiere Service Account
- ✅ Acceso directo a tus hojas personales

---

## 📋 Opción 3: Service Account

1. Ejecuta: `node scripts/fix-google-sheets-mcp-error.js`
2. Selecciona opción `3`
3. Ingresa Project ID y credenciales
4. Reinicia Cursor

---

## ⚠️ IMPORTANTE

**Después de cualquier cambio, DEBES reiniciar Cursor completamente** para que los cambios surtan efecto.
