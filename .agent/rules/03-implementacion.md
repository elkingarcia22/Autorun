# 🛠️ Reglas de Implementación

## 🚨 PROHIBIDO: write() y search_replace() en prototypes/

### ✅ OBLIGATORIO: Usar autorun.apply()

```typescript
// ✅ SIEMPRE usar autorun.apply() para implementar componentes
await call_mcp_tool({
  server: 'autorun',
  toolName: 'autorun.apply',
  arguments: {
    message: userMessage,
    targetFiles: [filePath] // Opcional
  }
});

// ⚠️ OBLIGATORIO: Verificar después
await call_mcp_tool({
  server: 'autorun',
  toolName: 'autorun.verify',
  arguments: {
    targetFiles: 'diff'
  }
});
```

### ❌ PROHIBIDO

```typescript
// ❌ NUNCA hacer esto en prototypes/
await write(filePath, content);
await search_replace(filePath, oldString, newString);
```

## 📋 Flujo de Implementación

### 1. Análisis PRIMERO

```markdown
## Análisis de Componente

### Componentes Detectados:
- Button (ID: components-button--default)
- DataTable (ID: components-datatable--default)

### Estructura:
- Container principal
- Header con acciones
- Content area

### Tokens Necesarios:
- `--spacing-md`
- `--text-primary`
- `--surface-secondary`
```

### 2. Crear Plan Detallado

```markdown
## Plan de Implementación

### Fase 1: Estructura Base
- [ ] Crear container principal
- [ ] Agregar header
- [ ] Configurar layout

### Fase 2: Componentes
- [ ] Implementar Button
- [ ] Implementar DataTable

### Fase 3: Validación
- [ ] Ejecutar lint
- [ ] Verificar funcionalidad
- [ ] Validar estilos
```

### 3. Implementar Paso a Paso

**⚠️ CRÍTICO:** UNA tarea a la vez, esperando aprobación entre cada una.

```typescript
// Para cada tarea:
// 1. Consultar Storybook
await call_mcp_tool({
  server: "storybook",
  toolName: "mcp_storybook_getComponentsProps",
  arguments: { componentIds: [componentId] }
});

// 2. Implementar con autorun.apply()
await call_mcp_tool({
  server: 'autorun',
  toolName: 'autorun.apply',
  arguments: { message: taskDescription }
});

// 3. Verificar
await call_mcp_tool({
  server: 'autorun',
  toolName: 'autorun.verify',
  arguments: { targetFiles: 'diff' }
});

// 4. Pedir aprobación
// 5. Continuar con siguiente tarea
```

### 4. Consultar Storybook OBLIGATORIO

#### Orden de consulta:

```typescript
// 1. PRIMERO: Historia "implementation" (copy/paste)
const implUrl = `https://ubits-storybook10.vercel.app/?path=/story/${componentId}--implementation`;
await browser_navigate({ url: implUrl });

// 2. SEGUNDO: Docs (documentación completa)
const docsUrl = `https://ubits-storybook10.vercel.app/?path=/docs/${componentId}--docs`;
await browser_navigate({ url: docsUrl });

// 3. ÚLTIMO: Default (solo si falta algo)
const defaultUrl = `https://ubits-storybook10.vercel.app/?path=/story/${componentId}--default`;
// Solo si necesario

// 4. Volver al template
await browser_navigate({ url: templateUrl });
```

## 🎯 Implementación por Historias de Storybook

### Para CADA historia (UNA a la vez):

1. ✅ Obtener checklist de la historia
2. ✅ Consultar la historia en Storybook 
3. ✅ Implementar SOLO esa funcionalidad
4. ✅ Completar TODO el checklist
5. ✅ NO continuar hasta completar checklist

### ❌ Errores Comunes:

- ❌ Usar historia "default" (tiene todo mezclado)
- ❌ Implementar múltiples historias al mismo tiempo
- ✅ Implementar UNA historia a la vez
- ✅ Completar checklist antes de continuar

## 🛡️ Sistema de Watermarks

Todo código generado por `autorun.apply()` incluye watermark:

```html
<!-- Generated by Autorun -->
<div class="ubits-component">
  ...
</div>
```

**⚠️ Si verify() detecta código sin watermark → REVERTIDO automáticamente**
