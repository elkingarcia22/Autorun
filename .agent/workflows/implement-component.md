# Implementar Componente UBITS

Este workflow guía la implementación de componentes UBITS usando las capacidades nativas de Antigravity.

---

## 🎯 Cuándo Usar Este Workflow

Usa este workflow cuando:
- El usuario pide implementar un componente UBITS (Button, DataTable, Tabs, etc.)
- Hay una imagen de diseño que incluye componentes UBITS
- Se necesita agregar funcionalidad con componentes del design system

---

## 📋 Prerequisitos

Antes de empezar:
- [ ] AutorunHub inicializado (`npm run autorun:init-hub`)
- [ ] Storybook local corriendo (`cd vendor/ubits/packages/storybook && npm run storybook`)
- [ ] Template HTML identificado (ej: `prototypes/canvas-*.html`)

---

```typescript

await browser_subagent({
  TaskName: "Extracting Component from Storybook",
  Task: `
    Navigate to http://localhost:6006
    
    1. Search for component "${componentName}" in search bar

    3. Click on "Show code" or "Code" tab

    6. Take screenshot for reference

  RecordingName: "storybook_extraction"

// URL: https://ubits-storybook10.vercel.app/?path=/story/${componentId}--implementation
```

### Paso 5: Implementar Componente

```typescript
// Usar replace_file_content o multi_replace_file_content
await replace_file_content({
  TargetFile: targetFilePath,
  TargetContent: "<!-- Punto de inserción -->",
  ReplacementContent: `
    <!-- Generated by Autorun with Antigravity -->
    <div class="component-wrapper">
      ${extractedHTML}
    </div>
  `,
  StartLine: insertionLine - 5,
  EndLine: insertionLine + 5,
  CodeMarkdownLanguage: "html",
  Instruction: `Insertar componente ${componentName}`,
  Description: `Agregado ${componentName} con props: ${JSON.stringify(props)}`,
  Complexity: 5
});
```

**Reglas críticas:**
- ✅ Usar tokens UBITS: `var(--spacing-md)`, `var(--text-primary)`, etc.
- ✅ NO agregar margin/padding extra a componentes
- ✅ Usar `gap` en contenedor padre para spacing
- ✅ Formato correcto de iconos: `fa-solid user` (no `fa-solid fa-user`)

## 🚨 Errores Comunes y Soluciones

### Error: Componente no se ve

**Causa:** Tokens no cargados o estilos incorrectos

**Solución:**
```html
<!-- Verificar que tokens estén importados -->
<link rel="stylesheet" href="../packages/proyecto-app/tokens/tokens.css">
```

### Error: Spacing incorrecto

**Causa:** Agregaste margin/padding al componente

**Solución:**
```css
/* ❌ NO hacer -->
.ubits-button {
  margin-top: 20px;
}

/* ✅ Hacer -->
.container {
  display: flex;
  gap: var(--spacing-md);
}
```

### Error: Iconos no aparecen

**Causa:** Formato incorrecto

**Solución:**
```html
<!-- ❌ Incorrecto -->
<i class="fa-solid fa-user"></i>

<!-- ✅ Correcto -->
<i class="fa-solid user"></i>
```
