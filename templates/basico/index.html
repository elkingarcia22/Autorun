Template Básico UBITS

Este template es simplificado y no usa ContentManager dinámico. Ideal para backend que necesita frontend listo para usar.

ℹ️ Información: Este template no requiere interceptaciones ni sistemas de gestión dinámica. Los componentes se inicializan directamente.

Características

  • ✅ Sin ContentManager dinámico
  • ✅ CSS local (no externo)
  • ✅ JS local (no externo)
  • ✅ Inicialización directa
  • ✅ Sin interceptaciones necesarias

Uso Básico

Para usar un componente:

  1. Copiar el CSS del componente a css/components/
  2. Copiar el JS del componente a js/components/
  3. Agregar el link CSS en el <head>
  4. Agregar el script JS antes del cierre de <body>
  5. Crear contenedor en el HTML
  6. Inicializar el componente con JavaScript

Ejemplo: RadioButton

Ver ejemplo completo en: examples/radio-button.html

<!-- HTML --> <div id="radiobutton-group"></div> <!-- CSS --> <link rel="stylesheet" href="css/components/radio-button.css"> <!-- JS --> <script src="js/components/radio-button.js"></script> <script> window.UBITS.RadioButton.create({ containerId: 'radiobutton-group', label: 'Opción 1', value: 'opcion1', name: 'grupo', checked: true }); </script>
⚠️ Nota: Este template NO usa ContentManager, por lo que el contenido es estático. Los componentes se inicializan directamente sin interceptaciones.
