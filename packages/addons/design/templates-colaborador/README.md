# Template Colaborador Add-on

Add-on de diseño que proporciona el template de colaborador para Autoframe.

## Características

- Template HTML completo para perfil colaborador
- Integración con el sistema de add-ons de Autoframe
- Configurable mediante `.ubits/project-config.json`

## Uso

Este add-on se activa automáticamente cuando se selecciona el perfil "colaborador" durante la inicialización del proyecto.
