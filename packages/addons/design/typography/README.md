# Typography Autoframe Add-on

Add-on de diseño que proporciona tipografía genérica de Autoframe.

## Características

- Fuentes: Noto Sans via Google Fonts
- Tokens de tipografía: Escalas, tamaños, pesos
- Integración con el sistema de add-ons de Autoframe
- Configurable mediante `.ubits/project-config.json`

## Uso

Este add-on se activa automáticamente cuando se selecciona durante la inicialización del proyecto.

## Archivos

- `fonts.css` - Fuentes (Noto Sans)
- `tokens-typography.css` - Tokens de tipografía (tamaños, pesos, líneas)
