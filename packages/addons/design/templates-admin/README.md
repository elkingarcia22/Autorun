# Template Administrador Add-on

Add-on de diseño que proporciona el template de administrador para Autoframe.

## Características

- Template HTML completo para perfil administrador
- Integración con el sistema de add-ons de Autoframe
- Configurable mediante `.ubits/project-config.json`

## Uso

Este add-on se activa automáticamente cuando se selecciona el perfil "admin" durante la inicialización del proyecto.
