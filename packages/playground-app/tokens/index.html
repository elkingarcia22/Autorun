Template UBITS

Sistema completo para crear aplicaciones UBITS con diseño system, componentes modulares, validación automática y despliegue.

🚀 Inicio Rápido

1. Clonar el Repositorio

git clone https://github.com/elkingarcia22/prototipo-template.git
cd prototipo-template

2. Instalar Dependencias

npm install

3. Inicializar el Proyecto

npm run init

Este comando interactivo te guiará paso a paso: solicita URL del repositorio GitHub, permite seleccionar perfil (Colaborador/Administrador), y configura el template automáticamente.

4. Iniciar Desarrollo

# Terminal 1: Auto-commit y validación
npm run watch

# Terminal 2: Servidor de desarrollo
npm run dev

🎯 Prompt Inicial para Cursor AI

Estás trabajando con el Template UBITS, un sistema completo para crear aplicaciones UBITS con diseño system, componentes modulares y validación automática.

Instrucciones para Cursor:

  1. Ejecuta npm run init y selecciona el perfil
  2. Usa npm run watch para auto-commit
  3. Siempre usa tokens UBITS para colores y tipografía
  4. Reutiliza componentes existentes
  5. Valida con npm run validate

📚 Prompt Inicial para Storybook

Estás trabajando con el Template UBITS en Storybook. Este template incluye componentes modulares, tokens de diseño UBITS y validación automática.

Instrucciones para Storybook:

  1. Ejecuta cd packages/docs-site && npm run storybook para iniciar Storybook
  2. Los componentes están documentados en packages/docs-site/stories/
  3. Usa los tokens UBITS para colores, tipografía y espaciado
  4. Reutiliza componentes existentes de packages/addons/
  5. Valida tus cambios con npm run validate

Componentes Disponibles en Storybook:

  • Sidebar - Con variantes colaborador/admin
  • TabBar - Con variantes colaborador/admin
  • SubNav - Navegación por pestañas
  • Button, Input, Card, Alert, Toast, Badge

Reglas Importantes:

  • Siempre usa tokens UBITS para colores y tipografía
  • Usa clases de tipografía oficiales (.ubits-heading-h1, .ubits-body-lg, etc.)
  • Reutiliza componentes existentes en lugar de crear nuevos
  • Mantén la consistencia con el diseño system

Grid y Breakpoints UBITS

Sistema de grid y breakpoints responsivos del sistema de diseño UBITS. Documentación completa del layout y puntos de quiebre.

Categorías
Breakpoints Sistema de Grid

Breakpoints

📱 Breakpoints

El sistema UBITS utiliza breakpoints responsivos para adaptar la interfaz según el tamaño de pantalla. Los breakpoints definen cuando cambian los componentes principales (Sidebar/TabBar).

Mobile < 480px

Pantallas pequeñas. TabBar visible, Sidebar oculta. Padding reducido (12px).

Tablet 480px - 767px

Pantallas medianas. TabBar visible, Sidebar oculta. Layout adaptativo.

Desktop 768px - 1023px

Pantallas grandes. TabBar visible, Sidebar oculta. Transición hacia Wide.

Wide ≥ 1024px

Pantallas extra grandes. Sidebar visible, TabBar oculta. Contenido centrado con max-width: 1607px (≥ 1440px).

🔑 Punto crítico

El breakpoint de 1024px es crítico: define el cambio entre Sidebar y TabBar. En max-width: 1023px se muestra TabBar, en min-width: 1024px se muestra Sidebar.

Sistema de Grid

📐 Sistema de Grid

El sistema de grid UBITS utiliza contenedores flexibles y secciones configurables para crear layouts adaptativos y consistentes.

Contenedores
.dashboard-container

Contenedor principal con display: flex y min-height: 100vh.

.main-content

Contenido principal: flex: 1, margin-left: 143px (sidebar), gap: 20px. En pantallas ≥ 1440px: max-width: 1607px centrado.

.content-area

Área de contenido: flex: 1, justify-content: center.

.content-sections

Contenedor de secciones: display: flex, flex-direction: column, gap: 16px.

Secciones de Widgets
.section-single

Una columna: display: flex, widget ocupa 100% del ancho.

.section-dual

Dos columnas: gap: 20px. En móvil (< 1024px): flex-direction: column, gap: 16px.

.section-triple

Tres columnas: gap: 20px. En móvil se apila verticalmente.

.section-quad

Cuatro columnas: gap: 20px. En móvil se apila verticalmente.

Widgets

Los widgets dentro de las secciones tienen:

  • background: var(--ubits-bg-1)
  • border-radius: 8px
  • padding: 16px (desktop) / padding: 12px (móvil ≤ 480px)
  • flex: 1 para distribución equitativa
Espaciado del Grid
Entre secciones: gap: 16px (20px entre SubNav y Content Area)
Entre widgets: gap: 20px (desktop) / gap: 16px (móvil)
Sidebar: width: 143px (24px + 96px + 23px gap)
Max-width contenido: 1607px (en pantallas ≥ 1440px)
