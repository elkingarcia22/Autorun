# 🚀 Empezar con Autorun

**Guía paso a paso para comenzar en menos de 5 minutos**

---

## 📋 Paso 1: Clonar e Instalar

```bash
# Clonar desde la rama correcta
git clone -b fase-1-tokens https://github.com/elkingarcia22/Autorun.git
cd Autorun

# Instalar (ejecuta verificación automática)
npm install
```

**✅ Verificación:** Si ves `✅ ¡Todo está listo! Puedes ejecutar: npm run init`, todo está correcto.

---

## 📋 Paso 2: Inicializar

```bash
npm run init
```

El wizard te preguntará:
1. **Tipo:** UBITS o Independiente
2. **Template:** Administrador o Colaborador (si UBITS)
3. **Módulo:** Aprendizaje, Desempeño, etc.
4. **Producto:** Producto específico del módulo

---

## 📋 Paso 3: Trabajar

Abre el lienzo creado en `prototypes/canvas-*.html` y comienza a prototipar.
