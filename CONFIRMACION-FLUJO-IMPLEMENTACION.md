## 📊 Flujo Detallado

### **Para Crear Dashboard/Home desde Imagen:**

1. **🔍 ANÁLISIS:**
   - Analizar componentes (Tabs, DataTable, Buttons, etc.)
   - Analizar iconos (con variaciones: simple, solid, etc.)
   - Analizar spacing (medir visualmente, NO asumir)
   - Analizar estructura (contenedores, orden de elementos)
   - Verificar componentes existentes (Sidebar, SubNav, Header - NO implementar)

2. **📋 PLAN:**
   - Crear plan detallado con todos los componentes
   - Dividir en tareas pequeñas
   - Mostrar plan al usuario
   - **ESPERAR aprobación explícita**

3. **✅ CHECKLIST:**
   - Para cada componente, crear checklist específico
   - Items: Consultar Storybook, entender funcionalidad, implementar, probar
   - Completar TODO el checklist antes de continuar

4. **🛠️ IMPLEMENTACIÓN:**
   - Implementar UNA tarea a la vez
   - Completar TODO el checklist de esa tarea
   - Probar que funciona
   - Pedir aprobación antes de continuar

---

### **Para Implementar un Componente Individual:**

**Ejemplo: "Implementa un DataTable"**

1. **🔍 ANÁLISIS:**
   - ¿Qué funcionalidades necesita? (paginación, búsqueda, filtros, etc.)
   - ¿Tiene checkboxes? (si SÍ, necesita Action Bar)
   - Consultar Storybook para ver todas las funcionalidades disponibles

2. **📋 PLAN:**
   - Obtener plan basado en historias de Storybook
   - Listar historias a implementar (UNA a la vez)
   - Mostrar plan al usuario

3. **✅ CHECKLIST:**
   - Para cada historia, crear checklist
   - Items: Consultar historia en Storybook, entender funcionalidad, implementar, probar

4. **🛠️ IMPLEMENTACIÓN:**
   - Implementar UNA historia a la vez
   - Completar TODO el checklist antes de continuar
   - NO implementar múltiples historias al mismo tiempo

## ⚠️ Reglas Críticas

### **❌ NUNCA Hacer:**
1. ❌ Implementar sin análisis primero
2. ❌ Implementar sin plan
3. ❌ Implementar sin checklist
4. ❌ Implementar todo de una vez
5. ❌ Saltarse items del checklist
6. ❌ Continuar sin aprobación del usuario

### **✅ SIEMPRE Hacer:**
1. ✅ Analizar primero (componentes, iconos, spacing, estructura)
2. ✅ Crear plan detallado
3. ✅ Mostrar plan y esperar aprobación
4. ✅ Crear checklist para cada componente/tarea
5. ✅ Implementar UNA tarea a la vez
6. ✅ Completar TODO el checklist antes de continuar
7. ✅ Probar después de cada tarea
8. ✅ Pedir aprobación antes de continuar
